Перед вами полноценна рабочая задача для аналитика
данных.

Контекст кейса и задача
Вы работаете в компании, которая управляет сетью аптек.
Бизнес переходит с упрощенной системы налогообложения
на общую. К вам подошел главный бухгалтер с просьбой
загрузить данные по всем 100 аптекам одним файлом в 1С.
Чтобы это сделать, неободимо сравнить данные из СБИС
с данными о реализации товара, которые передают аптеки.
